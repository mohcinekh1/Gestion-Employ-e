# Wireframe — Dashboard

## Zones

- Barre supérieure: nom utilisateur + rôle + bouton déconnexion
- Colonne gauche: menu (Dashboard, Employés, Absences, Salaires)
- Zone principale:
  - Cartes KPI (total employés, absences en attente, masse salariale)
  - Graphique répartition par département
  - Liste "Dernières activités"

## Règles UX

- Les KPI changent selon le rôle
- Un EMPLOYEE ne voit que ses propres indicateurs
