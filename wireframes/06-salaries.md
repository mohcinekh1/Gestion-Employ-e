# Wireframe — Gestion des salaires

## Zones

- En-tête: titre + bouton "Ajouter une fiche salaire" (ADMIN/MANAGER selon règle)
- Filtres:
  - Employé
  - Période
  - Type (MENSUEL/ANNUEL)
- Tableau:
  - Employé, Montant, Type, Date effet, Devise, Actions
- Modal ajout/modification:
  - Employé*
  - Montant*
  - Type*
  - Date d'effet*
  - Note

## Règles UX

- Format monétaire explicite (EUR)
- Historiser les salaires plutôt qu'écraser l'ancien montant
