# Wireframe — Liste des employés

## Zones

- En-tête page: titre + bouton "Ajouter un employé" (ADMIN)
- Barre d'outils:
  - Champ recherche (nom, email)
  - Filtre département
  - Filtre statut
- Tableau:
  - Colonnes: Nom, Email, Poste, Département, Statut, Date embauche, Actions
  - Actions: Voir, Modifier, Supprimer
- Pagination:
  - Taille de page (10/20/50)
  - Précédent / Suivant

## Règles UX

- Tri par colonne
- Confirmation obligatoire avant suppression
